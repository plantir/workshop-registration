# سامانه ثبت‌نام کارگاه‌های مرکز تحقیقات پزشکی ورزشی

یک وب‌اپلیکیشن کوچک (Flask + SQLite) برای ثبت‌نام دانشجویان در کارگاه‌ها با پنل مدیریت و خروجی اکسل.

## اجرا (بار اول)

1. [Python](https://www.python.org/downloads/) را نصب کنید (حین نصب گزینه‌ی **Add Python to PATH** را تیک بزنید).

2. در پوشه‌ی پروژه، Command Prompt (یا PowerShell) باز کنید و این دو دستور را اجرا کنید:

   ```
   pip install -r requirements.txt
   python app.py
   ```

3. در مرورگر:
   - **لندینگ پیج:** http://127.0.0.1:5000
   - **پنل مدیریت:** http://127.0.0.1:5000/admin (رمز پیش‌فرض: `sportmed1405`)

## بارهای بعدی

فقط `python app.py` را اجرا کنید. برای بستن، پنجره را Ctrl+C کنید.

## پوستر کارگاه

فایل پوستر دوره‌ی مرور سیستمیکی را با نام `systematic-review.jpg` در پوشه‌ی `static/posters/` قرار دهید
(اگر پوستر نباشد، به‌جای آن یک طرح گرافیکی نمایش داده می‌شود).

## افزودن کارگاه جدید

فایل `app.py` را باز کنید و در لیست `WORKSHOPS` یک دیکشنری جدید به همان شکل نمونه‌ها اضافه کنید.
`open: True` یعنی ثبت‌نام فعال است. کلید `poster` می‌تواند خالی باشد.

## تغییر رمز مدیریت

در `app.py` مقدار `ADMIN_PASSWORD` و `SECRET_KEY` را تغییر دهید.

## خروجی اکسل

در پنل مدیریت، برای هر کارگاه دکمه‌ی «خروجی اکسل» و در بالای صفحه دکمه‌ی «دانلود اکسل همه‌ی کارگاه‌ها»
(یک فایل با یک شیت جدا برای هر کارگاه) وجود دارد. ستون‌های خروجی:
ردیف، نام و نام خانوادگی، شماره دانشجویی، موبایل، ایمیل، مقطع، حوزه علاقه‌مندی، کارگاه، تاریخ ثبت‌نام.

## ذخیره‌ی داده‌ها

تمام ثبت‌نام‌ها در فایل `registrations.db` کنار همین فایل‌ها ذخیره می‌شوند؛ از این فایل بکاپ نگه دارید.

## فایل‌های رزومه

رزومه‌های آپلودشده‌ی دانشجوها در پوشه‌ی `uploads/` ذخیره می‌شوند و از پنل مدیریت (ستون «رزومه») قابل دانلود هستند.
فرمت‌های مجاز: PDF، Word، تصویر و ZIP — حداکثر ۵ مگابایت.

## فیلدهای فرم

نام و نام خانوادگی، شماره دانشجویی، موبایل، ایمیل، مقطع، **رشته‌ی تحصیلی** (متن آزاد)،
**ترم تحصیلی** (انتخابی از ترم ۱ تا ۱۴)، حوزه‌ی علاقه‌مندی (متن آزاد)، و رزومه (اختیاری).
برای تغییر لیست ترم‌ها، در `app.py` لیست `TERMS` را ویرایش کنید.
